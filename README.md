# Fonevia - Mobile E-commerce & Repair Platform

**Live Demo:** https://fonevia.onrender.com  
**Portfolio:** https://ardra-kp.github.io/ardrakp-portfolio/

Fonevia is a Django-based platform for buying, selling mobile phones and managing repair services for local shops.

### 🚀 Features
- **Marketplace:** Buy & sell new/used phones with search & filter
- **Role-Based Access:** Admin, Shop Owner, Customer dashboards
- **Repair Tracking:** Customers can track repair status in real-time
- **Shop Management:** Shop owners can manage inventory & repairs
- **Payments:** Razorpay integration
- **Responsive UI:** Mobile-friendly design

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite (Dev), PostgreSQL (Production ready)
- **Deployment:** Render
